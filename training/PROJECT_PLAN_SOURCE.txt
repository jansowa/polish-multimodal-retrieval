CEL PROJEKTU

Zbudować polski multimodalny embedder:
- zachować jakość PolDense w text↔text,
- maksymalizować text↔image i image↔text,
- później dodać composed retrieval typu CIRR/FashionIQ,
- jak najdłużej NIE ruszać text encodera.

Aktualny baseline:
- text encoder: PolDense, frozen
- vision encoder: frozen
- trainable: image projector
- trening na pełnej dostępnej puli ~70k
- MSCOCO text→image R@1 = 41.70 ± 0.20
- wcześniejszy pilot 6k = 13.07 R@1

To jest baseline E1 i wszystkie kolejne eksperymenty mają być porównywane do niego.

==================================================
P9 — COMPOSED RETRIEVAL
CIRR / FASHIONIQ
DOPIERO PO MOCNYM CORE MODELU
==================================================

Nie zmieniać bazowej przestrzeni embeddings.

Bazowy model:

text:
PolDense(text)

image:
Vision(image) → projector → PolDense-space

Dodać osobny composition head.

Dla:

reference image embedding = r
modification text embedding = t

[ ] 23. CIRR-A — prosta suma

q = normalize(r + alpha * t)

alpha:
- fixed albo learnable scalar

[ ] 24. CIRR-B — linear fusion

q = normalize(
    Linear(concat(r, t))
)

[ ] 25. CIRR-C — residual MLP

x = concat(
    r,
    t,
    r * t,
    r - t
)

delta = MLP(x)

q = normalize(r + delta)

Target:
embedding target image.

Train:
contrastive / ranking loss.

[ ] 26. Dodać CIRR hard negatives
Szczególnie obrazy z tej samej / podobnej grupy.

Composition head ma być dodatkiem.
Nie wolno degradować bazowego:
- text↔text
- text↔image
- image↔text
